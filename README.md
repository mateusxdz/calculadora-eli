## ✨ Funcionalidades

- 🧮 **Calculadora Científica Completa**:
  - Funções trigonométricas (`sin`, `cos`, `tan`), inversas (`asin`, `acos`, `atan`) e hiperbólicas (`sinh`, `cosh`, `tanh`).
  - Alternador dinâmico de modo angular: **Graus (DEG)** ou **Radianos (RAD)**.
  - Potências (`x²`, `x³`, `xʸ`), raízes (`√x`, `³√x`), logaritmos (`log`, `ln`), fatorial (`x!`), porcentagem e constantes ($\pi$, $e$).
  - Memória ativa (`MC`, `MR`, `M+`, `M-`, `MS`, `Ans`) e histórico persistente com até 50 cálculos.
  - Suporte completo a digitação por teclado físico.

- 🕰️ **Relógio Analógico de Alta Relojoaria (Eli Horloger 🌸)**:
  - Renderizado em HTML5 Canvas em alta definição (Retina/High-DPI).
  - Ponteiro de segundos com varredura contínua ultra-suave.
  - Display digital complementar com data e hora ao vivo em português.

- 📱 **Versão Mobile & PWA Nativa**:
  - Navegação fluida por abas segmentadas (`Calculadora`, `Relógio & Diva`, `Histórico`).
  - Resposta tátil com vibração háptica em smartphones compatíveis.
  - Teclado científico retrátil para digitação rápida com o polegar.
  - Suporte para instalar como Web App na tela inicial do celular.

- 💖 **Card Interativo da Ariana Grande**:
  - Foto editorial exclusiva em alta definição.
  - Mini equalizador de áudio animado.
  - Frases e vibes pop que mudam a cada toque com explosão de confetes e estrelas.

## 🚀 Como Publicar no GitHub Pages

Este projeto está pronto para publicação direta no **GitHub Pages**:

1. Crie um novo repositório vazio no seu GitHub (exemplo: `projeto-eli` ou `calculadora-eli`).
2. No seu terminal local dentro desta pasta, adicione o endereço do repositório remoto:
   ```bash
   git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
   ```
3. Envie os arquivos para a branch principal (`main`):
   ```bash
   git push -u origin main
   ```
4. No GitHub, acesse:
   - **Settings** (Configurações do repositório) -> **Pages** (no menu lateral esquerdo).
   - Em **Source**, selecione **GitHub Actions** (ou **Deploy from a branch** -> branch `main` / pasta `root` -> **Save**).
5. Em menos de 1 minuto, seu site estará no ar no endereço:
   ```
   https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO/
   ```
